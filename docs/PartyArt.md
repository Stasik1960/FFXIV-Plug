# Party Art 0.1.0

Автор: **Ringoto**. Отдельный плагин для Dalamud API 15, который по запросу отправляет заданный рисунок из символов в чат группы `/p`. Все 45 строк, подчёркивания и символы `¶` сохранены в исходном порядке. Остальным участникам плагин устанавливать не нужно.

## Установка и использование

Добавьте общий каталог в `/xlsettings` → Experimental → Custom Plugin Repositories:

```text
https://raw.githubusercontent.com/Stasik1960/FFXIV-Plug/main/repo.json
```

Если ссылка уже добавлена для другого плагина Ringoto, обновите список `/xlplugins`, найдите **Party Art** и установите его.

1. Вступите в игровую группу хотя бы с одним другим игроком.
2. Откройте `/partyart`: в окне есть предпросмотр и интервал между строками от 1 до 5 секунд.
3. Нажмите **Отправить в группу** или выполните `/partyart send`. Первый ряд отправляется сразу, остальные по очереди. По умолчанию пауза составляет 1,5 секунды, весь рисунок занимает примерно 66 секунд.
4. Кнопка остановки, команда `/partyart cancel` (также `/partyart stop`) или закрытие окна отменяют оставшиеся строки. Сворачивание до заголовка сохраняет текущую отправку.

Отправка начинается только по запросу, без автоматического повтора. Повторный запрос во время отправки не добавляет ещё один рисунок в очередь. Перерыв в работе игры не вызывает отправку накопившихся строк пачкой. При выходе из группы или игры, смене персонажа, группы или локации, загрузке, ролике и отключении плагина оставшиеся строки отменяются. Чтобы начать заново, нажмите кнопку снова.

## Особенности чата

Каждая строка — отдельное обычное сообщение в `/p`. Плагин не меняет текущий выбранный канал. В альянсе рисунок увидит своя группа, поскольку используется `/p`.

Счётчик «Передано игре» означает вызов локального игрового чата; сервер не возвращает плагину подтверждение доставки. Ограничения чата и фильтры игры продолжают действовать. Если игра пропускает строки, остановите отправку и увеличьте интервал. Другие сообщения участников могут вклиниваться между строками, а узкое окно чата и шрифт могут повлиять на вид рисунка. В предпросмотре используется моноширинный шрифт.

## Сборка

```powershell
./scripts/build.ps1
./scripts/package-party-art.ps1 -ReleaseTag v0.1.0
```

Пакет: `plugins/PartyArt/0.1.0/PartyArt.zip`, рядом находится SHA256. Проверки логики выполняются без подключения к игре и без отправки настоящих сообщений.
