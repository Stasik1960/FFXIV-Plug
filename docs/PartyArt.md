# Party Art 0.2.0

Автор: **Ringoto**. Заготовки сообщений с ручной отправкой и автоматическим запуском по игровым событиям. Встроенный рисунок из версии 0.1.0 удалён. Новая версия начинает с пустой библиотеки: добавьте собственные тексты.

## Установка

В `/xlsettings` → Experimental → Custom Plugin Repositories добавьте каталог:

```text
https://raw.githubusercontent.com/Stasik1960/FFXIV-Plug/main/repo.json
```

Если ссылка уже добавлена, обновите список `/xlplugins` и обновите **Party Art** до **0.2.0**. Плагин нужен только отправителю, сервер не требуется.

## Создание заготовки

Откройте `/partyart`, нажмите **+ Новая заготовка**, задайте название и введите сообщения: каждая непустая строка — отдельное сообщение. Можно вставить сразу много строк. Количество заготовок и сообщений не ограничено плагином; действуют доступная память и ограничение игры на размер одного сообщения. Лимит — 500 байт UTF-8 вместе с префиксом канала. Ошибочная строка подсвечивается, и вся заготовка блокируется до исправления.

Выберите канал: **Группа /p**, **Альянс /a** или **Только мне /echo** для локальной проверки. Нажмите **Отправить сейчас** либо выберите события и включите **Запускать по выбранным событиям**. Общий переключатель **Автоматическая отправка** управляет всей автоматикой. Новые заготовки не имеют назначенных событий; копии создаются с выключенным автоматическим запуском.

Библиотека поддерживает поиск, копирование и удаление. Несколько выбранных событий запускают одну и ту же последовательность сообщений. Сохраняются порядок строк, канал и текст на момент запуска. Изменение заготовок отменяет активную очередь, чтобы отключённые или удалённые тексты не продолжали отправляться.

## Автоматические события

| Событие | Что отслеживается |
| --- | --- |
| Вход в подземелье / задание | Переход в новое задание; отправка после загрузки и вступительного ролика. |
| Начало задания | Игровое событие Duty Start. При входе в уже начатое задание используйте событие входа. |
| Победа / завершение задания | Успешное завершение всего задания, обычно после последнего босса. |
| Вайп группы | Игровое событие полного поражения группы. |
| Повторная попытка после вайпа | Игровое событие Duty Recommence. |
| Вход в бой | Персонаж перешёл в боевое состояние. |
| Выход из боя | Любое прекращение боя, включая поражение или отход. |
| Мой персонаж погиб | Переход живого персонажа в состояние смерти. |
| Мой персонаж воскрес | Обратный переход в живое состояние. |
| Я вступил в группу | Переход из одиночной игры в группу. |
| В группу пришёл игрок | Изменение доступного состава текущей группы. |
| Игрок покинул группу | Уход участника из доступного состава текущей группы. |

Начальная загрузка плагина и вход персонажа устанавливают исходное состояние без рассылки задним числом. Недоступные слоты группы не считаются выходом игроков. Бой и смерть отслеживаются только по доступным данным; после загрузки исходное состояние устанавливается заново. Переход между территориями внутри одного задания с тем же ContentFinderCondition не повторяет приветствие.

События задания берутся из [IDutyState Dalamud](https://github.com/goatcorp/Dalamud/blob/master/Dalamud/Plugin/Services/IDutyState.cs). Произвольная победа над промежуточным боссом отдельным надёжным событием здесь не отслеживается.

## Отправка и управление

- `/partyart` — открыть окно.
- `/partyart send Название` — вручную запустить заготовку с уникальным названием. Без названия работает, если в библиотеке ровно одна заготовка.
- `/partyart cancel` или `/partyart stop` — остановить всю текущую очередь.
- `/partyart on` и `/partyart off` — включить или выключить автоматику.

Ручной запуск доступен и заготовкам с выключенным автоматическим запуском. Закрытие и сворачивание окна сохраняют автоматику; для полной паузы выключите общий переключатель. Кнопка остановки очищает текущую очередь, последующие новые события по-прежнему могут срабатывать.

Настройки содержат общий интервал **1,5–10 секунд** и переключатель **Волк на фоне**. Фон по умолчанию включён. Одна очередь обслуживает все заготовки, отправляя максимум одно сообщение за обновление без накопленных пачек после зависания. Глобальная пауза сохраняется между заготовками, отменой и новым ручным запросом. Одна заготовка не может одновременно находиться в очереди дважды и не запускается повторно в течение 15 секунд после постановки.

Чтобы устаревшие события не накапливались, в ожидании допускается до 32 заготовок; ожидающая заготовка старше 30 секунд отменяется. Уже начатая заготовка отправляется целиком без ограничения числа сообщений. Это ограничение очереди не ограничивает размер библиотеки.

Выход из игры, смена персонажа, группы или локации и отключение плагина отменяют очередь. Загрузка или ролик отменяют уже запущенные сообщения. Новые события самого задания, возникшие во время ролика или вайпа, могут ждать готовности чата до пяти минут в той же группе и локации. Смена контекста отменяет их.

## Ограничения чата

Плагин использует обычные `/p`, `/a` и `/echo`. Счётчик «Передано игре» означает локальную передачу команды, без подтверждения доставки сервером. Публичного гарантированного «безопасного» интервала у игры нет: пауза 1,5 секунды — нижняя граница настройки, ограничения сервера продолжают действовать.

Если игра выдаёт известное сообщение об ограничении последовательных команд, очередь очищается и автоматическая отправка выключается. Сообщение игры остаётся видимым, автоматических повторов нет. Увеличьте интервал перед повторным включением. Определение использует ID 3810, 3999 и 10196 через [IChatGui.LogMessage](https://github.com/goatcorp/Dalamud/blob/master/Dalamud/Plugin/Services/IChatGui.cs), сверенные с [таблицей LogMessage](https://github.com/xivapi/ffxiv-datamining/blob/master/csv/en/LogMessage.csv).

## Сборка

```powershell
./scripts/build.ps1
./scripts/package-party-art.ps1 -ReleaseTag v0.2.0
```

Пакет: `plugins/PartyArt/0.2.0/PartyArt.zip`, рядом SHA256. Исходники и тесты не требуют запуска игры. Нативную отправку, работу событий конкретного задания и оформление окна нужно проверять в игре.
